# Audio licenses

Every sound and music file shipped with Race Track Mayhem is **CC0 1.0 (public domain dedication)**:
https://creativecommons.org/publicdomain/zero/1.0/

| Files | Author | Source | License |
|---|---|---|---|
| Sound effects, voices, jingles, UI sounds | Kenney (www.kenney.nl) | Starter Kit Racing, Starter Kit 3D Platformer, Impact Sounds, Digital Audio, Voiceover Pack, Music Jingles, UI Audio, Interface Sounds | CC0 (see `KENNEY-CC0.txt`) |
| Tire skid / brake sound | Landeplage | Kenney's Starter Kit Racing (https://github.com/KenneyNL/Starter-Kit-Racing) | CC0 |
| Music (menu, garage, race, results) | Juhani Junkala | "5 Chiptunes (Action)", https://opengameart.org/content/5-chiptunes-action | CC0 |

Where the files came from: the original sites (kenney.nl, opengameart.org) couldn't be reached from the
build machine, so the files were taken from GitHub copies of the same packs:
- https://github.com/KenneyNL/Starter-Kit-Racing and https://github.com/KenneyNL/Starter-Kit-3D-Platformer (official)
- https://github.com/Calinou/kenney-interface-sounds and https://github.com/Calinou/kenney-ui-audio
- https://github.com/ETdoFresh/kenney.nl (copies of Kenney packs including their License.txt)
- https://github.com/ensisoft/gamestudio (copy of the Juhani Junkala tracks)

The countdown beeps, whoosh, rev and the fallback sounds are generated in code (`scripts/sfx.gd`).
See also `assets/audio/CREDITS.md`.
